# 操作模式定义

Phase 1 识别 UI 模式 → Phase 2 展开用例套件 → Phase 3 智能编排 + Playbook 执行。

---

## 模式总览

| 模式 | 标签 | 识别条件 | 标准套件数 |
|------|------|---------|-----------|
| Create | `[Create]` | "新增/添加/创建"按钮 + 弹窗/抽屉/新页面表单 | 5-6 |
| Read | `[Read]` | 表格/卡片列表 + 搜索/筛选 + 分页 | 5-7 |
| Update | `[Update]` | "编辑"入口 + 预填充表单 | 2-3 |
| Delete | `[Delete]` | "删除"按钮 + 二次确认 | 2 |
| FormSave | `[FormSave]` | 编辑器/表单 + 保存按钮（非弹窗，页面内直接编辑） | 1-2 |
| Toggle | `[Toggle]` | checkbox/switch 开关 | 2 |
| ModalSearch | `[ModalSearch]` | 弹窗内搜索 + 列表 + 选择/添加 | 2-3 |
| TabNav | `[TabNav]` | Tab/标签页组件 | 每 Tab 1 条 |
| ViewSwitch | `[ViewSwitch]` | 列表/卡片/网格切换按钮组 | 每视图 1 条 |
| Publish | `[Publish]` | 发布/上线按钮 + 确认弹窗 | 1-2 |
| Bookmark | `[Bookmark]` | 星标/收藏图标 | 2 |
| Upload | `[Upload]` | 上传按钮/拖拽区 | 4-6 |
| Export | `[Export]` | "导出"/"下载"按钮 | 2-3 |
| BatchAction | `[BatchAction]` | 全选 checkbox / 批量操作按钮 / 多选后出现操作栏 | 5-6 |
| TreeView | `[TreeView]` | 树形结构 / 组织架构树 / 目录树 / 分类树 | 4-5 |

## Create（新增）

**识别条件**：页面存在"新增"/"添加"/"创建"/"+ 新增"按钮，点击后弹出弹窗/抽屉/跳转到新页面，包含表单。

**标准用例套件**：

| 序号 | 用例 | 优先级 | 操作摘要 | 预期 |
|------|------|--------|---------|------|
| C1 | 正常创建 | P0 | 填写所有必填字段 → 确认 | 成功提示 + 列表新增记录 |
| C2 | 必填校验 | P1 | 不填任何字段 → 确认 | 显示必填错误提示 |
| C3 | 取消创建 | P2 | 填写部分字段 → 取消 | 弹窗关闭 + 数据未创建 |
| C4 | 关闭弹窗 | P2 | 点击 X 关闭 | 弹窗关闭 + 数据未创建 |
| C5 | 字段边界值 | P2 | 输入超过最大长度（具体长度值从 Phase 1 功能分析报告的字段校验规则提取，如 maxlength=50 则输入 51 字符） | 截断或提示 |
| C6 | 重复值 | P2 | 输入已存在的唯一字段值 | 提示已存在或允许重复 |

**数据标注**：`creates: "{实体名}"` — 标记此用例会创建测试数据。

## Read（列表查询）

**识别条件**：页面存在表格/卡片列表 + 搜索框/筛选器 + 分页器。

**标准用例套件**：

| 序号 | 用例 | 优先级 | 操作摘要 | 预期 |
|------|------|--------|---------|------|
| R1 | 默认加载 | P0 | 进入页面 | 列表正常显示，数据条数正确 |
| R2 | 搜索-正常 | P0 | 输入已知关键词搜索 | 过滤后仅显示匹配项 |
| R3 | 搜索-无结果 | P2 | 输入不存在的关键词 | 空状态/暂无数据 |
| R4 | 搜索-清空恢复 | P2 | 清空搜索框 → 搜索 | 恢复全部数据 |
| R5 | 分页-翻页 | P1 | 点击第 2 页 | 显示第 2 页数据 |
| R6 | 分页-跳页 | P2 | 跳页输入框输入页码 | 跳转到指定页 |
| R7 | 分页-切换每页条数 | P2 | 切换 pageSize（如 20/50/100 条/页） | 列表刷新为对应条数，分页器更新 |

## Update（编辑）

**识别条件**：存在"编辑"入口（按钮/图标/菜单项），点击后弹出预填充表单。

**标准用例套件**：

| 序号 | 用例 | 优先级 | 操作摘要 | 预期 |
|------|------|--------|---------|------|
| U1 | 修改并保存 | P1 | 修改某字段值 → 确认 | 成功提示 + 列表更新 |
| U2 | 修改其他字段 | P1 | 修改另一类字段（如标签/分类） | 成功提示 |
| U3 | 清空必填字段 | P2 | 清空必填字段 → 确认 | 显示校验错误 |

**数据标注**：`depends: "TC-XXX"` — 如果编辑的是 Create 用例创建的数据。

## Upload（文件上传）

**识别条件**：上传按钮/拖拽区域，接受文件输入。

**标准用例套件**：

| 序号 | 用例 | 优先级 | 操作摘要 | 预期 |
|------|------|--------|---------|------|
| UP1 | 正常上传 | P1 | 选择合规文件上传 | 上传成功 |
| UP2 | 格式限制 | P2 | 上传不支持的格式 | 提示格式错误 |
| UP3 | 大小限制 | P2 | 上传超限文件 | 提示大小超限 |
| UP4 | 多文件上传 | P1 | 同时选择多个合规文件上传 | 全部上传成功，文件列表正确显示 |
| UP5 | 拖拽上传（如支持） | P2 | 将文件拖拽到上传区域 | 上传成功（需 Playwright MCP 支持 browser_drag） |
| UP6 | 上传进度/状态验证 | P2 | 上传较大文件 → 观察进度条/状态 | 显示上传进度，完成后状态变为"已完成" |

**嵌入规则**：当 Upload 作为 Create/Update 流程的一部分时（如创建向导中包含文件上传步骤）：
1. module.patterns 必须同时列出 Upload（不可仅标注 Create）
2. Upload 独有的边界用例（UP2/UP3）应独立生成为单独的测试用例，不与 Create 的 C1 合并
3. Create 的 C1（正常创建）中包含正常上传即可，不需要在 C1 中测试 Upload 边界

## Export（导出/下载）

**识别条件**：页面存在"导出"/"下载"/"Export"按钮，点击后触发文件下载或显示导出进度。

**标准用例套件**：

| 序号 | 用例 | 优先级 | 操作摘要 | 预期 |
|------|------|--------|---------|------|
| EX1 | 正常导出 | P1 | 点击导出按钮 | 触发文件下载或显示"导出成功/开始下载"提示 |
| EX2 | 空数据导出 | P2 | 筛选到 0 条数据后点击导出 | 提示"无可导出数据"或下载空文件 |
| EX3 | 导出文件验证 | P2 | 导出后检查下载文件 | 文件格式正确且非空（检查下载事件或 evidence 目录） |

**注意事项**：Export 是只读操作，不修改数据。Phase 1 探索阶段如导出是 X-禁止操作，标注为"受限跳过 ⏭️"，Phase 3 执行阶段验证。

## BatchAction（批量操作）

**识别条件**：页面存在全选 checkbox / 批量操作按钮（如"批量删除""批量导出"）/ 勾选多条记录后出现操作栏。

**标准用例套件**：

| 序号 | 用例 | 优先级 | 操作摘要 | 预期 |
|------|------|--------|---------|------|
| BA1 | 全选勾选/取消 | P1 | 点击表头全选 checkbox → 再次点击取消 | 全选时所有行被选中；取消时所有行取消选中 |
| BA2 | 部分选择 | P1 | 勾选 2-3 条记录 | 被勾选行高亮/选中，操作栏显示已选数量 |
| BA3 | 批量删除 + 确认弹窗 | P1 | 勾选多条 → 点击批量删除 → 确认 | 确认弹窗出现 → 确认后选中记录从列表移除 |
| BA4 | 批量导出（如有） | P2 | 勾选多条 → 点击批量导出 | 导出成功提示或文件下载 |
| BA5 | 跨页选择保持（如有分页） | P2 | 第 1 页勾选 → 翻到第 2 页勾选 → 执行批量操作 | 跨页选择的记录均被包含在操作中 |
| BA6 | 空选择时操作按钮禁用 | P2 | 不勾选任何记录 → 查看批量操作按钮 | 批量操作按钮置灰/禁用，或点击后提示"请先选择" |

**数据标注**：BA3 如果批量删除的是 Create 创建的数据，标注 `consumes: "TC-XXX"`。

## TreeView（树形视图）

**识别条件**：页面存在树形结构，如组织架构树、目录树、分类树、菜单树等，通常有展开/折叠图标（+/-/▶/▼）。

**标准用例套件**：

| 序号 | 用例 | 优先级 | 操作摘要 | 预期 |
|------|------|--------|---------|------|
| TV1 | 展开/折叠节点 | P1 | 点击父节点展开图标 → 再次点击折叠 | 子节点显示/隐藏 |
| TV2 | 多级嵌套展开 | P1 | 依次展开多级父节点（根→子→孙） | 每级子节点正确显示，层级缩进正确 |
| TV3 | 选择叶子节点 | P1 | 点击叶子节点 | 节点被选中/高亮，关联内容正确加载 |
| TV4 | 搜索定位到目标节点 | P2 | 在树搜索框输入关键词 → 搜索 | 匹配节点高亮或自动展开到目标节点 |
| TV5 | 拖拽排序（如支持） | P2 | 拖拽节点到新位置 | 节点顺序/层级更新（需 Playwright MCP 支持 browser_drag） |
