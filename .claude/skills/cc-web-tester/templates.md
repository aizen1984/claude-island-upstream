# 测试用例 JSON 模板（xmind 生成输入）

此 JSON 作为 `scripts/generate-xmind.py` 的输入，生成 .xmind 思维导图文件。

```json
{
  "title": "[网站名称] 测试用例",
  "url": "[URL]",
  "date": "[YYYY-MM-DD]",
  "modules": [
    {
      "name": "模块/页面名称",
      "patterns": ["Create", "Read", "Update", "Delete"],
      "cases": [
        {
          "id": "TC-001",
          "title": "用例简要描述",
          "priority": "P0",
          "pattern": "Create",
          "precondition": "前置条件描述",
          "steps": [
            "步骤 1",
            "步骤 2"
          ],
          "expected": "预期结果描述",
          "data_lifecycle": {
            "creates": "实体名或null",
            "depends": "TC-XXX或null",
            "consumes": "TC-XXX或null"
          }
        }
      ]
    }
  ]
}
```

**字段说明**：
- `patterns`（module 级）：该模块包含的操作模式列表，用于 xmind 模块标题标注
- `pattern`（case 级）：该用例对应的操作模式
- `data_lifecycle`（case 级）：测试数据生命周期标注，用于智能编排
  - `creates`: 该用例创建的测试数据实体名
  - `depends`: 该用例依赖的前置用例 ID
  - `consumes`: 该用例会清理的数据对应的创建用例 ID

**模块分组规则**：与测试用例.md 中的页面/功能分组保持一致，每个页面或功能区域作为一个 module。

# batch 执行结果模板

子 agent 写入 `evidence/batch-{N}.md` 的格式：

```markdown
# Batch {N} 执行结果

- **执行时间**: [YYYY-MM-DD HH:mm]
- **用例范围**: TC-{起始} ~ TC-{结束}
- **结果**: 通过 [X] | 失败 [Y] | 阻塞 [Z] | 跳过 [W]
- **停止原因**: {正常完成|连续失败暂停|max_turns 耗尽}

---

### TC-{编号}: {描述} [{通过|失败|阻塞|跳过}]

- **预期结果**: {从用例复制的预期结果}
- **实际结果**: {具体描述页面上观察到的内容，禁止写"符合预期"}
- **执行数据**:
  - 输入数据: {填写的表单值、选择的选项等}
  - 关键响应: {页面提示文案、toast 内容、跳转 URL 等}
  - 数据变化: {列表新增/修改了哪条记录、状态从X变为Y等；无数据变化时写"无"}
- **结果截图**:

![TC-{编号} 结果截图](screenshots/TC-{编号}-result.png)

- **失败截图**: {有则如下，无则写"无"}

![TC-{编号} 失败截图](screenshots/TC-{编号}-fail.png)

- **步骤截图**: {有则逐张列出，无则写"无"}

![TC-{编号} 步骤截图](screenshots/TC-{编号}-step-{M}.png)
- **备注**: {失败原因/阻塞原因或空}

### TC-{编号}: {描述} [{通过|失败|阻塞|跳过}]

...
```
