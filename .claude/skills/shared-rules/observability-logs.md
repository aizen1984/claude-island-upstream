# 可观测性日志规范

> **加载时机**：每次 Skill 激活时。让 skill 系统从黑盒变为白盒。

## 1. Skill 激活确认

```
📋 使用模板：[模板名称]
🔧 已激活能力：[能力列表]
📂 资源加载：
  ├─ SKILL.md (Core)
  └─ [按需文件] ← [原因]
```

## 2. 运行时日志格式

| 场景 | 格式 |
|------|------|
| 按需资源加载 | `📂 加载: [skill]/[文件] ← [原因]` |
| Agent 派发 | `🤖 派发: [agent类型] ← [来源skill].[阶段] \| 任务: [subject]` |
| Skill 间委托 | `🔗 [源skill].[阶段] → [目标skill或/command] \| 原因: [触发条件]` |
| 隐式依赖预加载 | `📂 预加载依赖: [skill]/SKILL.md ← [skill名称]隐式依赖` |
| 研究阶梯 | `🔬 研究 S{n} {代码库\|知识库\|网络} \| 主题: [subject] \| 结果: {确信→决策\|升级→S{n+1}}` |

`🔗` 委托日志示例：
```
🔗 cc-planner.EXECUTE → /cc-ralph | 原因: 策略4 (任务≥3 且 预估>15min)
🔗 cc-api-analyzer.AGGREGATE → cc-diagram | 原因: 表数量>5 自动委托
```

## 3. Vault 检索日志

每次检索 Obsidian Vault 时打印检索过程和结果：

```
📖 Vault [项目名] L{最终层级}
  路径: L0(CLI搜索"{关键词}"→{命中数}篇) → L1({文档名}:快速熟悉[{行号范围}]) [→ L2({章节名}[{行号范围}])]
  耗行: 索引{N}行 + L1 {N}行 [+ L2 {N}行] = 共{总行数}行
  结论: {一句话摘要}
```

无命中时：`📖 Vault [项目名] ⚠️ 无命中 | 关键词: {xxx} | 退化: Grep/代码分析`

## 4. IO 统计

- 单次：`📊 IO: [skill]/[file] [全量|offset:limit] → {N}行 (累计{total}行)`
- 汇总（Skill 执行结束时）：`📊 上下文消耗: [skill] 共加载 {N} 文件 {total} 行`

仅统计 Skill 自身资源文件读取，不含用户项目代码。

## 5. 图标速查

| 图标 | 含义 |
|------|------|
| `📋` `🔧` | 模板名/能力列表 |
| `📂` | 资源加载 |
| `🤖` | Agent 派发 |
| `🔗` | Skill 间委托 |
| `📖` | Vault 检索 |
| `📊` | IO 统计/上下文消耗 |
| `🔍` | 对抗验证 |
| `🔬` | 研究阶梯（S1 代码→S2 知识库→S3 网络） |
| `❓` | 询问决策 |
