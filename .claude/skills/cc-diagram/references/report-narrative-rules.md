# 报告叙事规则（SCQA + 认知科学驱动）

> 从 cc-diagram SKILL.md 提取。适用于所有生成数据分析报告的场景。

## 报告整体结构（SCQA + 四幕叙事弧）

```
开场（SCQA）：
  S 情境：1-2 句共识事实（锚定读者，如"T0 扣款成功率 3 月稳定在 82%"）
  C 冲突：1-2 句打破平衡（如"3/11 起断崖式下降到 78%"）
  Q 问题：读者此刻脑中的疑问（隐含或显式）
  A 答案：核心结论 1 句（如"根因是两个运营操作叠加导致的池子结构变化"）

正文（四幕递进）：
  1. Hook — 一个反常数字抓注意力
  2. Rising Insights — 3-4 个关键发现逐步叠加（各用 Assertion-Evidence 展开）
  3. Aha Moment — 核心洞察 + 因果归因
  4. Next Steps — 具体可执行的行动建议
```

## 叙事质量规则（认知科学驱动）

> 基于工作记忆 4±1 限制（Cowan 2001）、金字塔原理（Minto）、渐进式披露（NN/g）、因果叙事（Dykes）。

| # | 规则 | 原理 | 应用 |
|---|------|------|------|
| N1 | **每层 ≤4 项** | 工作记忆同时处理 3-5 个 chunk | 顶层论点最多 4 个，每段要点最多 4 个，表格 ≤5 列 |
| N2 | **结论先行** | 金字塔纵向逻辑：上层概括下层 | 每段首句是结论，有兴趣再往下读 |
| N3 | **同层 MECE** | 金字塔横向逻辑：不重叠不遗漏 | 同组论点按统一维度排列（时序/因果/结构），不混用 |
| N4 | **因果不跳步** | 因果链每环用「因为/导致/所以」显式连接 | A→B→C 不省略 B，段间用桥梁句（上段结论=下段前提） |
| N5 | **渐进披露** | 读者按需停读 | L0 摘要（所有人）→ L1 关键证据（决策者）→ L2 详细过程（执行者） |
| N6 | **统一术语** | 减少认知切换成本 | 同一概念全文同一名称，不换用近义词 |
| N7 | **首尾衔接** | 连贯性保障 | 每段首句承接上段，尾句预告下段 |
| N8 | **新概念必须铺垫+数据支撑** | 防认知跳跃 | 首次引入任何新术语/新指标/新维度，必须同时满足两条：①桥梁句说明「为什么要看这个」；②给出数据定义和量化证据。禁止出现"无来源断言" |

## N8 反模式（最常见的阅读断裂）

**模式 A：新指标无铺垫**
- 错误：上段说"审完搭售量暴跌 39%"，下段直接甩"终态成功率/CANCEL 率/整体成功率"三个新指标
- 正确：桥梁句「量减少 ≠ 率降低。需要验证 AUDIT 用户质量是否更高，用三个维度对比：」→ 再放表格

**模式 B：新术语无数据支撑**
- 错误：直接写"更多低质量边际用户涌入分母"
- 正确：先定义+给数据，让读者能质疑你的推导

## 自检方法

写完后逆序阅读每段首句，应能串成一个完整的逻辑链。如果某句孤立读不通，说明上下文衔接断裂。额外检查：每张表格/图表上方是否有「为什么要看这个」的铺垫句。
